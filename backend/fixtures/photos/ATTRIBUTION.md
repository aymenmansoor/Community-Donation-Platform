The cup image is used only for a new fictional cup-and-saucer listing; the clock image only for a new fictional wall-clock listing. They are not falsely attached to books, clothing or toys. Existing genuine images are never replaced. Existing fictional listings still need suitable licensed category photographs: Pexels/Wikimedia download hosts are currently blocked by runtime policy. The network additions are saved in the environment draft. Verify each remaining source's author/licence before using it; do not assume that every file in an image-sample repository shares a licence.
